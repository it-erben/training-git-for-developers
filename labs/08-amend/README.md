# Lab 08: Commits ändern mit Amend

Mit `git commit --amend` kannst du den letzten Commit nachträglich korrigieren — sowohl den Inhalt als auch die
Commit-Nachricht. Ideal für vergessene Dateien oder Tippfehler.
