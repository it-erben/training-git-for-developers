# Utils

Gemeinsame Hilfsskripte, die von den `setup.sh`/`setup.ps1`-Skripten der einzelnen Labs verwendet werden.

| Datei | Beschreibung |
|-------|--------------|
| [utils.sh](utils.sh) | Gemeinsame Shell-Funktionen für Lab-Setups |
| [make-exercise-repo.sh](make-exercise-repo.sh) | Erstellt ein lokales Git-Repository als Übungsumgebung (Bash) |
| [make-exercise-repo.ps1](make-exercise-repo.ps1) | Erstellt ein lokales Git-Repository als Übungsumgebung (PowerShell) |
| [make-fake-remote.sh](make-fake-remote.sh) | Erstellt ein lokales Bare-Repository als simuliertes Remote |
| [make-bare-remote-repo.ps1](make-bare-remote-repo.ps1) | Erstellt ein lokales Bare-Repository als simuliertes Remote (PowerShell) |
| [clone-remote-to-exercise.sh](clone-remote-to-exercise.sh) | Klont ein simuliertes Remote in ein Übungsverzeichnis (Bash) |
| [clone-remote-to-exercise.ps1](clone-remote-to-exercise.ps1) | Klont ein simuliertes Remote in ein Übungsverzeichnis (PowerShell) |
| [make-setup.sh](make-setup.sh) | Generiert Setup-Skripte für neue Labs |
| [resources/](resources/) | Zusätzliche Ressourcen (z.B. Merge-Testdateien) |
| [test/](test/) | Tests für die Setup-Skripte |
