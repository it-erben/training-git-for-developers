# Lab 05: Fast-Forward-Merge

Führe einen Feature-Branch per Fast-Forward in `master` zusammen. Dabei wird der Branch-Zeiger einfach vorgerückt, ohne dass ein Merge-Commit entsteht — die Historie bleibt linear.
